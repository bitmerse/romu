# Romu Hardware Files

Romu is an open-hardware project, and this folder is where its hardware design files will live.

The files are not published yet. They will be added here **before units ship to backers**.

## What will be published

- Schematics
- PCB design files
- Bill of materials (BOM)
- 3D enclosure STL files

## License

Once published, the hardware design files will be released under [CERN-OHL-P-2.0](LICENSE.txt).
